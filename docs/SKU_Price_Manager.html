CHITEK SKU 价格体系

基础价只按 电流 / 容量档 + 价格分类（机型·电压） 定；小屏、壁挂、SiC、ASVG、中频炉、延保 走统一加价规则，不单独建 SKU。 数据源：盘厂底价表（图1）+ 价格说明（图2），2026-10-21 录入，单位 = 人民币元。
底价可直接改，改完自动存本机。
型号规则：M + 机型位（A=高防护 / D=分布式 / L=高压）+ 类型位（F=APF / G=SVG）+ 三位电流或容量 + 电压接线位（34=400V三相四线 / 43=480V三相三线 / 63=690V / 83=800V）+ RC。
改数值后立即生效，报价计算同步更新。

商务条款（随报价附带，不进单价）

  • 质保期：发货后 24 个月或上电后 15 个月，以先到为准。
  • 延长质保：每年价格 +3%。
  • 付款条件：到货后一个月。
  • 标准交货期：一周。
  • 应用告知：中频炉应用价格上浮 20%；中频炉及偶次谐波应用需提前告知。
