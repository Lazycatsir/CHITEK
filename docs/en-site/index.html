一、怎么用

  • 日常管理 → 直接开 index.html（或对应的 .html），用浏览器打开就能看，不需启动站点。
  • 源码改过之后 → 重跑 python docs/en-site/_gen/gen_en_site_docs.py，两份格式（html + md）一起刷新。
  • 要交给别人 / 贴进文档 → 用同名的 .md，纯文本表格，可直接粘进任何文档系统。
  • 待补清单里的「建议新 href」列 → 在 html 里看、在 md 里填，或直接改 02-download-links.md。
