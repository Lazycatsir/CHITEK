CHITEK 网站管理手册不编程、只说话。对 OpenCode 说人话，它帮你改网站。

你的角色：内容管理者，不需要写代码。
OpenCode 的角色：网站管理员，听你的指令改代码并发布。

OpenCode（opencode.ai）是免费开源工具。你对它说人话，它会：

  • 读取项目说明文档理解规则
  • 修改对应的源代码文件
  • 运行 npm run build 确保网站能正常构建
  • 提交并推送到 GitHub，Netlify 自动将新版部署上线
✅ 最重要的安全保证

构建失败 ≠ 网站挂掉。 就算改错了、构建失败了，线上网站依然显示旧版本，不会白屏。修复后重新推送即可。

2. 需要准备什么

✅ 项目文件夹里已有全部代码和文档

你只需要装几个软件、配一次推送密钥。之后全部让 OpenCode 操作。

2.1 必装软件

软件版�版去哪下载做什么用
OpenCode最新版opencode.ai 下载桌面版你说话的窗口、管理网站的操作员
Node.js22.xnodejs.org跑网站构建工具，必须 22 版
Git最新版git-scm.com代码版本管理、推送到 GitHub

你不需要：注册 GitHub 账号、登录 Netlify、了解部署过程。OpenCode 会搞定。

2.2 安装步骤（逐条做）

1
装 OpenCode
到 opencode.ai 下载桌面版安装。完成后打开，会看到聊天界面。
2
装 Node.js 22.x
到 nodejs.org 下载 LTS 版（22.x），一路"下一步"安装。
📖 看不懂安装界面？参考图文教程：《Node.js 安装及环境配置超详细教程（win11 为例）》（含下载、安装选项、验证 node -v / npm -v、换国内镜像）
3
装 Git
到 git-scm.com 下载安装，全部选默认。
📖 安装时每个步骤不知怎么选？参考图文教程：《Git 详细安装教程（详解每个步骤）》（含 PATH、OpenSSH、换行符、终端等 15 个安装选项说明）
4
生成推送密钥
打开终端（按 Win+R → 输入 cmd → 回车），运行：
ssh-keygen -t ed25519 -f "%USERPROFILE%\.ssh\chitek_deploy" -N ""
然后把生成的公钥发给交接人：
type "%USERPROFILE%\.ssh\chitek_deploy.pub"
复制屏幕上输出的整行文字，发给交接人。他在 GitHub 配置好后你就可以推送了。
5
拿到项目文件夹并装依赖
交接人把 CHITEK 文件夹给你（U盘或网盘），在文件夹里按 Shift+右键 → 打开 PowerShell，运行：
npm install
等它跑完不报红字就行。

2.3 交接人（原开发者）要做的事

#事项操作说明状态
1给你项目文件夹把整个 CHITEK 文件夹复制给你（U盘/网盘）□ 未完成
2配置 Deploy Key你提供公钥（就是上面第 4 步输出的内容）给他，他加到 GitHub
仓库 → Settings → Deploy keys → Add deploy key，勾 Write access		□ 未完成
3确认远程仓库地址正确在项目文件夹运行 git remote -v，应显示 git@github.com:Lazycatsir/CHITEK.git□ 未完成

💡 配好 Deploy Key 后，你就拥有"只管推代码、其他什么都不用管"的权限。推了自动上线。

3. 日常任务手册（核心）

以下每个任务都是"对 OpenCode 说的话"。照抄复制粘贴，把 [方括号] 里的内容换成你的实际信息即可。

📰 任务 1：发布新新闻文章

最常见5-10 分钟

✅ 你准备什么
  • 写好文章正文（纯文字，不需要排版）
  • 如果有配图：把图片文件（jpg/webp/png）放在 public/assets/images/news/ 文件夹里，文件名如 news-img-21.webp
  • 如果没有配图，OpenCode 会自动用已有图片

对 OpenCode 说的话（整个复制过去，改 [方括号] 里的）：

请帮我在网站发一篇新闻文章。

文章标题：[填写标题]
类别：[Technology / Case Study / Product Update / Industry News / Sustainability]
发布日期：[2026-07-24]
文章图片：[填写图片文件名，如 news-img-21.webp；没有就删掉这行]

正文：
[把整篇文章贴在这里]

要求：
1. 先读 README.md 和 CLAUDE.md 里的新闻发布规范
2. 先创建中文版（src/pages/news/xxxx.astro）
3. 翻译成英文、西语、阿语三个版本
4. 葡语（pt）不需要新闻，跳过
5. 在 4 个语言的新闻列表页各插入一张新卡片，按日期降序放在正确位置
6. 运行 npm run build 确认构建通过
7. 推送到 GitHub
⏱ 这时 OpenCode 会做这些（你可以等着看）
  1. 读项目文档了解新闻文章结构和格式
  2. 生成中文版 .astro 文件（frontmatter + HTML 正文 + SEO 标签）
  3. 翻译成英文/西语/阿语版本，各 1 个文件
  4. 在 4 个语言的新闻列表页插入新卡片
  5. 运行 npm run build 确认构建通过
  6. git add → git commit → git push 推送到 GitHub
✅ 怎么检查发布成功
  1. 上网站 chitek-inno.com/news 看列表里是否有新文章
  2. 点进去看内容是否正确
  3. 检查英文 en.chitek-inno.com/news 也有同一篇
  4. 如果没显示：等 1-2 分钟再刷（Netlify 构建需要时间）。如果还不行，参考第 5 节

💡 如果 OpenCode 中途停下来问问题，回答"按项目惯例处理"即可。

💡 如果构建失败，OpenCode 会自动修复后重试。连续 2 次修不好，参考第 5 节。

✏️ 任务 2：修改页面文字

最简单2-5 分钟

场景 A：只改一个语言的一处

把[英文]首页 hero 区域的副标题从"旧的文字"改成"新的文字"。
只改这一处，其他语言不动。
改完后构建验证，没问题就推送。

场景 B：5 个语言同步改同一段话

把 Products 页顶部标题从"xxx"改成"yyy"，5 个语言同步改。
中文：yyy
英文：yyy 的英文翻译
西语：yyy 的西语翻译
阿语：yyy 的阿语翻译
葡语：yyy 的葡语翻译
改完后跑 build 确认，推送。

💡 不确定翻译时让 OpenCode 自动翻："把首页的'xxx'改成'yyy'，翻译成 5 个语言版本"。

🖼️ 任务 3：更换图片

简单3-5 分钟

✅ 你准备什么
  • 新的图片文件（推荐 webp 格式）
  • 把图片放到 public/assets/images/ 下对应的子目录
我把新图片放在了 public/assets/images/products/新图片.webp。
请把中文首页的 hero 背景图换成这张。
改完启动 dev server 预览确认，构建通过后推送。

💡 不确定替换哪张图，截图给 OpenCode 问："这个区域用的是什么图？"

📄 任务 4：加一个全新页面

不常用15-30 分钟

请帮我创建一个新页面。

页面路径：/en/new-product
页面名字：New Product Name
导航菜单里要显示这个链接

参考 src/pages/en/products/active-harmonic-filter.astro 的结构来做。
页面主要内容：
[描述你要放什么——标题、段落、表格、图片等]

完成后创建中文/西语/阿语/葡语版本（5 个语言全部做好）。
在导航栏和各语言首页添加链接。
构建验证后推送。

💡 加新页面是技术性最重的操作。效果不对时截图给交接人，不用自己调。

🌐 任务 5：把一个语言的改动同步到其他语言

不常用

我把[英文]的产品页改了：[简单描述改了什么]。
请把同样的修改同步到中文、西语、阿语、葡语版本。
注意：只改结构和类名，不要动各语言的翻译文本。
改完后确认 5 个版结构一致，构建验证后推送。

↩️ 任务 6：网站回滚到旧版本（出了问题也不怕）

紧急1-2 分钟

✅ 构建失败不需要回滚

只有"新版上线后发现内容错了"才需要回滚。构建失败的话，线上还是旧版本，不用回滚。

方法：让 OpenCode 回滚

刚刚推送的版本有问题，帮我回滚到上一个版本。
用 git revert，构建通过后推上去。

⚠️ 任务 7：构建失败了 / 网站没更新

✅ 先确认：是不是"还没发布"

推送后需要 1-3 分钟构建，期间网站仍显示旧版本。等 3 分钟再刷。

对 OpenCode 说：

网站好像没更新。帮我检查：
1. 运行 npm run build 看有没有报错
2. 如果有报错，修复
3. 检查 git push 是否成功
4. 修复后重新构建并推送

OpenCode 连续 2 次修不好：

  1. 把报错红字复制下来（或者截图）
  2. 发给交接人
  3. 同时做回滚（任务 6）恢复网站到已知正常的版本

4. 检查清单

✅ 你和交接人一起逐条确认

4.1 软件安装

  • OpenCode 已安装并能打开
  • Node.js 22.x 已安装（终端运行 node --version，输出以 v22 开头）
  • Git 已安装（终端运行 git --version，有版本号）
  • 项目文件夹已在你的电脑上
  • 在项目文件夹运行 npm install 成功（无红色报错）

4.2 权限配置

  • 已生成 SSH 密钥并将公钥发给交接人
  • 交接人已把 Deploy Key 加到 GitHub 仓库（勾了 Write access）
  • 远程仓库地址是 SSH 格式（终端运行 git remote -v，显示 git@github.com:Lazycatsir/CHITEK.git）

4.3 最终验证（最重要，逐条做一遍）

  • npm run dev 能启动，浏览器访问 localhost:4321 能看到网站
  • npm run build 成功（终端最后显示 Completed，无红字）
  • 任意改一个文字后，对 OpenCode 说"提交并推送"能成功推送到 GitHub（OpenCode 不报错）
  • 等 2 分钟后刷新公网网站（比如 chitek-inno.com），改动已生效

5. 故障排查

OpenCode 停下来问问题，不知怎么答

说："按项目惯例处理，继续就行。"

构建报红字错误

对 OpenCode 说：修复构建错误，重复跑 build 直到通过。

连续 2 次修不好：报错截图发交接人。

构建成功但网站没变

  1. 确认推送成功：问 OpenCode "git push 有报错吗？"
  2. 浏览器强制刷新：Ctrl+Shift+R（或清除缓存）
  3. 等 3 分钟后再次刷新
  4. 还不行：截图发交接人

网站完全不显示了（白屏/404）

不要慌，先刷新几次（可能临时问题）。 仍然白屏的话立刻联系交接人。

💡 白屏通常是临时配置问题，不会导致数据丢失。

找不到了这个手册

在项目文件夹里打开 OpenCode，说：读 docs/站点管理手册.html 给我看。
