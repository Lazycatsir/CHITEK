0 · 怎么用这份东西

原来那张图是一套方法论骨架——4 根支柱（市场位置 → 增长来源 → 成交放大 → 优势持续性）从「它是谁」一路推到「它为什么还能继续赢」，骨架是对的，可以直接留用。

但它写的是消费品牌 / DTC 电商的语言：bundle、满减、赠品、订阅、分期、Upsell、耗材复购、Referral 裂变。CHITEK 卖的是 AHF / SVG 这类工业电力电子设备——单台几十公斤、进盘柜、进招标短名单、决策链 3–7 个人、周期 1–6 个月、寿命 10 年以上。原图里大约有一半内容搬过来会落不了地。

这份文档只做三件事，不重复原图：
  • 指出原框架直接套到工业设备上的 3 个失灵点（第 1 节）；
  • 给出 DTC → AHF/SVG 的翻译表，把原图每个概念换成工业场景里的等价物（第 2 节）；
  • 把 4 根支柱各自展开成 「问题 → 去哪查 → 判断标准 → 产出」 四层模块，并补上行业竞品候选名单、可引用的市场事实底稿、一页纸填报模板（第 3–10 节）。

1 · 原框架在工业 B2B 上的 3 个失灵点

原图的 4 根支柱不用改，但它默认了三个前提，这三个前提在 AHF / SVG 上都不成立：

#原框架的隐含假设在 AHF / SVG 上为什么失灵改成什么（本手册的修正层）
1 决策链短：看到广告 → 点击 → 访问页面 → 下单成交。漏斗是「人 → 点击 → 页面 → 付款」。 真实链路是 触达 → 询盘 → 有效询盘 → 技术方案 → 报价 → 打样 / 验厂 → 中标签约，周期 1–6 个月。中间至少 3 个角色会否决：电气工程师（参数对不对）、设计院 / EPC（能不能画进图）、采购与业主（价格与资质）。「下单」这个词在这里不存在，只有「签约」。 漏斗改为：
触达 → 询盘 → 有效询盘 → 报价 → 签约 → 复购（多站点）
每个环节单独看转化率，不要只看总询盘。
2 转化靠 Offer：折扣、满减、bundle、赠品、订阅、分期。 没人会因为「满 10 万减 5 千」签一台 AHF。工业采购的成交依据是另外四件事：参数对得上、认证进得去、案例有人用过、交期与售后敢写进合同。价格只是筛子，不是钩子。 Offer 改为：
① 资质包（IEC 62477 / CE / UL 证书 + 第三方检测报告）
② 首台样机 / 试用
③ 项目报备与独家保护
④ 多站点框架协议价
⑤ 年度维保与备件包
3 复购靠耗材 / 会员：Replacement、订阅、会员升级、Referral 裂变。 AHF / SVG 是 10 年以上寿命、几乎无耗材的设备。没有「每月续费」这件事。真实的复购来自四个方向：同一客户的其他站点、同一站点的容量扩容、SiC 换代升级、经销商与盘柜厂的下一次采购。 复购路径改为：
单点成交 → 同集团多站点复制 → 集团框架协议 → 白标 / OEM 贴牌 → 备件与扩容
结论：原图可以直接用的部分 = 支柱一、二、四（判断对手的定位、增长、壁垒），以及支柱三的「承接页信息顺序」。 支柱三里所有交易机制部分（Offer / 复购设计）必须换成上面这套 B2B 版本，否则整节是空的。

3.2 拓展：原图没有问、但在电能质量行业必须问的 8 个问题

原图的「目标人群」在 DTC 语境里就是年龄 / 性别 / 收入。工业设备的「人群」= 买方结构 + 决策角色，这是完全不同的东西。下面 8 问是按重要性排序的补充。

#拓展问题为什么重要判断口径
1它的主 SKU 容量段在哪？低压有源滤波器里 50–200 A 段占约 39%，是主流竞争区。它在哪个段站稳，决定它抢哪个标段；也决定我们和它是正面撞还是错位。列出它全部型号的容量范围（A / kvar），标出主力型号（官网排位靠前、展会主推的那个）
2它的认证清单覆盖哪些市场？认证是工业品的通行证，不是加分项。缺 UL 就进不了北美 NEMA 市场，缺国网入围就拿不到国内电网项目。逐条列：IEC 62477 / CE / UL / GB-T 14549 / 国网南网入围 / 防爆或 IP 等级
3它是自有产线还是贴牌代工？决定它的成本底线与扩产速度。贴牌商不敢打价格战到底，自有产线商敢；但要警惕反过来的情况——贴牌商反而更能压价，因为它不背固定资产。有没有工厂照片 / 产线视频 / SMT 车间；是「研发制造」还是「解决方案提供商」措辞
4它的区域重心在哪？国际平台商多在欧美本地生产，中国厂商多靠出海。区域错开时不构成直接竞争，报告里要分开写，否则判断会跑偏。官网语言版本、区域站、经销商分布地图、展会举办地
5它的买方是谁：EPC / 盘柜厂 / 终端工厂 / OEM 贴牌？四类买方的需求完全不同：EPC 要交期与图纸，盘柜厂要尺寸与接口，终端工厂要案例与售后，OEM 要白标与价格。搞错买方，话术全错。看它在网站上主推什么：图纸下载 → 服务 EPC；接口说明 → 服务盘柜厂；案例 → 终端；白标政策 → OEM
6它的价格锚在哪？（同容量段报价区间）原图的「价格带」在电商里是标价，在这里是不公开的。只能通过渠道询价、展会报价、国际站区间价反推。用同一容量段（如 100 A AHF）横向问 3 家渠道价，记区间不做结论
7它的产品线结构是「系列化」还是「一柜通吃」？2026 年出现了明显信号：多家厂商把 AHF + SVG + DVR 合并成一个柜体 SKU，说明行业预期客户会「从一家买齐」。它是做深一个品类，还是做宽一个柜子？产品导航是「按系列分」还是「按一台柜子能干什么分」
8它的品牌阶段，用什么证据判定？原图给了 4 个阶段的名称但没给证据标准。判错阶段会导致对策错位（比如对一个平台期巨头打「快速迭代」牌没有意义）。见下方 3.4 判断标准表

4.3 拓展：判断它的增长引擎是哪一个（原图只看「做了什么」，这里看「靠什么」）

原图让你数它做了哪几个渠道。更关键的判断是：它这盘生意是被真需求拉起来的，还是被投放砸出来的。区分方法如下。

引擎查什么证据说明什么
① SEO / 内容拉动blog / news 是否有按行业分组织的长文；是否做选型对比页（AHF vs SVG vs 无源）；是否有工具页（选型计算器）；站点是否分语言 / 分区域最耐久。有内容资产的厂商，广告停下来询盘不会归零
② 付费投放推动Google 搜核心词看广告位有没有它；LinkedIn 是否在做定向；B2B 平台是不是最高等级会员增长看着快，但停投即停。看它落地页能不能承接——如果只有平台店铺没有官网产品页，说明靠买流量
③ 展会与地面推一年几场、展位面积、展品是否 SiC 新品、展位照片里有没有客户围观工业设备非常有效，但一年只能打几次，且有强地域性
④ 渠道网络经销商分布页、代理政策文件、是否有区域独家、是否有本地库存增长慢但质量高。能拿到区域独家说明品牌已有议价力
⑤ 贴牌 / 代工拉动是否为其他品牌代工；产品与某品牌是否长得像；是否有白标政策量大利薄、无品牌资产。增长数字好看但不可持续，也学不来

客户心里的默认答案它什么时候赢我们要提供什么才能改掉它
「用大牌更保险」项目大、责任重、决策人要担责时第三方检测报告 + 可查的认证编号 + 同行业同规模案例。用可核验的第三方证据替代品牌信任
「先不治理，罚点钱算了」罚款金额不明确、或没人被追责时把总成本算出来（罚款 + 电容柜损毁 + 设备寿命 + 电费），做成一张可发给客户的成本对照页
「换个便宜的先用」预算被砍、或对效果没有预期时用「同类容量段的效率与寿命差异」讲清总持有成本，而不是比首台价格
「自己做，或拿现有电容柜改」厂内有机电工程师、追求内部方案时提供选型工具与技术支持，先成为「顾问」，再成为供应商
「等等看，国产替代会降价」技术标准未变、没有合规压力时给出时间成本：设备过热与良率损失是按天计费的，等待本身有成本

8.4 标准、选型红线与共性失效模式

这一节是内容选题与销售话术的直接素材——竞品的失效模式，就是我们的切入话术。

项内容

共性失效模式
（可直接做选题）		① AHF 选型不足 → 客户新上变频器后谐波谱变化 → 设备在满电流下长期运行而过热；

③ 电容方案 → 共振放大 5 / 7 次谐波，严重时烧电容柜。
