审计对象：F:\下载\CHITEK\src\pages\en 下全部 .astro 页面（核心页 + 新闻页）。生成于 2026-09-18。

1. 字体系统总览

全站只使用 2 个字族：

  • Barlow —— 正文默认字族。BaseLayout.astro 的 <body class="font-barlow ..."> 让所有元素默认继承 Barlow。
  • Barlow Condensed —— 标题字族，仅当某个元素显式带 font-barlow-condensed 类时才生效。
关键发现（"有些看起来不一样"的结构性原因）：
global.css 只定义了 --font-barlow-condensed 这个 CSS 变量（第 154 行），没有任何全局 CSS 规则把 h1/h2/h3/h4 强制设为 Condensed。 标题是否用 Condensed，取决于每个元素自己有没有写 font-barlow-condensed 类。结果就是：同一个页面、甚至在"看起来都像标题"的位置，有的渲染成 Barlow（宽），有的渲染成 Barlow Condensed（窄）——视觉上明显不一致。

3. 为什么"有些看起来不一样"——根因分析

字重（加粗程度）和字符调整（字距 / 大小写）是逐元素、逐页面手工写的，全站没有统一的"字号 / 字重 / 字距"刻度表（type scale）。三类不一致叠加，导致观感不统一：

3.1 标题字族不统一（Condensed 占比对照）

核心页面Barlow 元素数Condensed 元素数说明

新闻页几乎全是 Barlow（Condensed 占比≈0%）；而 about / index / products 详情页大量使用 Condensed。跨页跳转时，标题"宽窄"会突然变化。

3.2 同一逻辑位置字重不一致

  • products/active-harmonic-filter.astro：标题级大量用 Condensed + font-bold（700） 34 处，外加 Condensed + font-semibold + tracking-[0.2em] 11 处（超宽字距）。
  • products/sic-ultra-ahf.astro：标题级几乎不用 Condensed（仅 6 处 bold），主体是 Barlow + font-semibold（600） 34 处 + Barlow + font-medium（500） 15 处——比上者"细"且"宽"。
  • services.astro：用 Condensed 默认字重（400）+ tracking-[-0.02em] 10 处（细且收紧）+ Barlow + font-medium（500） 46 处，整体观感又不同。

3.3 字符调整（字距 / 大小写）随心所欲

  • 字距跨度极大：tracking-tight（-0.025em，收紧，新闻正文 32 处）、tracking-wide（+0.025em，about/index 13 处）、tracking-[0.2em]（超宽，active-harmonic-filter 11 处）、tracking-[0.15em]（about 9 处）、tracking-[-0.02em]（services 10 处）、tracking-[0.05/0.06/0.08/0.1em] 散落在 index/contact/about。
  • 大小写混用：uppercase 在 Condensed bold（14）、Barlow bold（10）、Barlow 默认（9）、Barlow semibold（5）等处反复出现，没有统一"标签用大写"的规则。
结论：新闻页内部高度一致（Barlow + bold/semibold + tracking-tight），观感统一；不一致集中在核心页（about / contact / index / products / 产品详情 / services / solutions），它们之间的字重、字距、是否用 Condensed 差异明显。若要让"看起来都一样"，需要给全站定一套统一的 type scale（字号 + 字重 + 字距 + 何时用 Condensed），再批量归一化核心页。
