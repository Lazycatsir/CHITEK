3. 为什么颜色也会“看起来不一样”——发现与建议

整体结论：英文站文本颜色比字体更收敛——正文/标题基本只用 text-text-dark(#1a1a1a) 与 text-text-muted(#6b7280)，强调色统一是 text-brand-orange(#ff6b1a)。 不一致主要来自两类“绕过 token”的写法，而不是调色板本身发散：
  • ① 命名冗余 token：--color-electric-orange 与 --color-brand-orange 同为 #ff6b1a；--color-text-primary(#264653) 与 --color-brand-navy 同值；--color-text-secondary(#6d6875) 与 --color-brand-gray 同值。两套名字指同一颜色，易让人误以为是两种色。建议保留一套（orange / navy / gray），废弃另一套别名。
  • ② 混用默认 Tailwind 灰度 + arbitrary 硬编码：在自定义 token（如 text-text-muted=gray-500 #6b7280）之外，还大量直接用默认调色板 text-gray-400(#9ca3af, 159)、text-gray-600(#4b5563, 60)、text-gray-700(#374151, 72)、text-gray-900(#111827) 与 arbitrary text-[#111827](171)——#111827 同时出现两种写法；另有写死的非 token 色 text-[#a8401e](168，深橙) 与 text-[#0000EE](138，链接蓝)。灰度/强调色来源不统一，主题换色时这批不会跟随。建议：gray-* 与 arbitrary 全部改回自定义 token（#111827→可新增 text-ink 或复用 text-dark；#0000EE→新增链接 token；#a8401e→text-brand-orange-dark）。
