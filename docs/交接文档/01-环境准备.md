# 环境准备 —— 需要安装什么

## 软件清单（按安装顺序）

### 1. OpenCode —— 你的"管理员"
OpenCode 是免费的 AI 编程助手，你在聊天框里说人话，它帮你改代码并发布。

- **下载**：[opencode.ai](https://opencode.ai) → 选你的系统（Windows/macOS/Linux）
- **安装方式**：
  - **推荐**：下载桌面版（Desktop Beta），有图形界面
  - 或终端安装：`curl -fsSL https://opencode.ai/install | bash`
- **模型选择**：内置免费模型可用，推荐连接 Claude（效果好），需要自己的 API Key

**安装后验证**：在终端输入 `opencode --version`，有输出版本就 OK。

### 2. Node.js —— 跑网站构建工具
必须是 22.x 版本（项目依赖这个版本）。

- **下载**：[nodejs.org](https://nodejs.org/) → 选 22.x LTS
- **安装**：一路 Next，全默认选项
- **验证**：打开终端（cmd/PowerShell），输入 `node -v`，应显示 `v22.xxx`

### 3. Git —— 代码版本管理
- **下载**：[git-scm.com](https://git-scm.com/downloads) → 选你的系统
- **安装**：一路 Next，全默认
- **验证**：终端输入 `git --version`，有输出即可

### 4. GitHub 账号 —— 存代码的地方
- 注册 [github.com](https://github.com)（免费）
- **必须操作**：把账号名告诉给你的交接人，他把仓库加入协作（或者 Fork）
- 之后你会拿到仓库地址：`git@github.com:Lazycatsir/CHITEK.git`

### 5. Netlify 账号 —— 网站部署和域名
- 注册 [netlify.com](https://netlify.com)（免费）
- **必须操作**：告诉交接人你的 Netlify 账号邮箱，他把站点权限移交给你
- 交接完成后，你登录 Netlify 能看到构建日志和域名设置

拿到交接人给的仓库权限和 Netlify 权限后，按 `02-首次启动.md` 完成初始化。这些只需做一次。
