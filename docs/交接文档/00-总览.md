# CHITEK INNOPOWER 站点 —— 交接总览

## 这是什么

CHITEK INNOPOWER 的 B2B 工业官网，5 语言（中文/英文/西语/阿语/葡语），部署在 Netlify，源码托管在 GitHub。

你拿到这个文件夹后，不需要会编程。日常维护（加新闻、改文字、换图片）通过 **OpenCode** 用自然语言完成。OpenCode 会读项目里的说明文档，知道怎么操作。

## 交接包里有什么

```
docs/交接文档/          ← 你在看的这份
├── 00-总览.md          ← 本文件，项目概览
├── 01-环境准备.md       ← 装什么软件、注册什么账号
├── 02-首次启动.md       ← 第一天要做什么
├── 03-日常任务手册.md    ← 对 OpenCode 说什么（核心！）
└── 04-工具清单.md       ← 全部依赖和敏感信息清单

CLAUDE.md               ← AI 读的项目操作说明（含完整编码规范）
README.md               ← 项目首页 + 快速开始 + 文档地图（2026-09-18 起）
docs/NEWS_PIPELINE.md   ← 新闻发布流水线 + 15 条踩坑记录（原 README.md 正文）
.workbuddy/memory/      ← 项目工作日志 + 专题规范（AI 会自己读的）
```

## 一句话技术架构

| 层 | 技术 | 作用 |
|---|------|------|
| 框架 | Astro 6.x | 生成静态 HTML |
| 样式 | Tailwind CSS v4 | 原子化 CSS |
| 部署 | Netlify | 自动构建 + CDN |
| 代码托管 | GitHub | 存源码，推了自动触发构建 |
| 内容管理 | OpenCode | 你说的→它改代码→它推→Netlify 上线 |

## 核心安全事实

**构建失败 ≠ 网站挂掉。** Netlify 保留上一次成功部署的版本。改坏了最坏结果是网站不更新，不会白屏。
