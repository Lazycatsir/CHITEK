# 日常任务手册 —— 对 OpenCode 说什么

**核心原则：把 OpenCode 当你的网站管理员。** 你用自然语言说"我要什么"，它会做全部技术操作、验证、提交和发布。

---

## 任务 1：发一篇新新闻文章

### 你准备什么
- 写好文章正文（纯文字即可，不用排版）
- 配图（如果有）：一张 1200×630 左右的图，放在 `public/assets/images/blog/` 里

### 对 OpenCode 说的话

```
请帮我在网站发一篇新新闻文章。以下是我准备好的内容：

文章标题：《XXX》
类别（选一个）：Technology / Case Study / Product Update / Industry News / Sustainability
发布日期：YYYY-MM-DD
正文：

[把文章正文贴在这里]

1. 先读 `CLAUDE.md`（项目规则）和 `docs/NEWS_PIPELINE.md`（新闻发布规范）
2. 按中文版先创建 src/pages/news/xxxx.astro
3. 翻译成英文、西语、阿语三个版本（四语 **slug 必须一致**）
4. 跑 `npm run news:sync` 自动重写列表数据（**列表页已是数据驱动，不用再手插卡片**）
5. `npm run news:check` + `npm run build` 验证通过
6. 推送到 GitHub
```

> **注意**：
> - 葡语（pt）**不需要**新闻页
> - 如果没有配图，OpenCode 会自动用已有的通用图
> - 如果有图片，告诉它："图片放在 public/assets/images/blog/xxx.webp"

## 任务 2：改首页的某段文字

### 对 OpenCode 说的话

```
请把中文首页的 hero 区域的副标题从 "xxx" 改成 "yyy"。
只改中文版，其他语言不动。
改完后用 npm run dev 预览确认，再推送到 GitHub。
```

> **注意**：如果其他语言也要改，后面加上："同步改成英文版为 'yyy'，西语为 'zzz'，阿语为 'www'。"

---

## 任务 3：首次启动 + 运行验证

### 对 OpenCode 说的话

```
打开终端，在当前项目目录运行 npm run dev，然后在浏览器访问 http://localhost:4321/，确认网站能正常显示。
```

## 任务 4：换一张首页产品图片

### 告诉 OpenCode

```
把中文首页的 active-harmonic-filter 区域的主图换成 public/assets/images/ 下的新图片文件 xxx.webp。
改完用 dev server 预览确认。
```

## 任务 5：修改 5 个语言共有的页面结构/动画

### 对 OpenCode 说的话

```
我现在需要 [描述改动内容，比如"把英文 products 页的 Four Product Series 区域放到 hero 下方"]。
先改英文版，然后按 astro-i18n-sync 的流程同步到中文、西语、阿语、葡语。
改完后确认 5 个版本一致，构建通过后推送。
```

> OpenCode 会自动读 CLAUDE.md 里的 i18n 同步规范，不用你操心细节。

---

## 任务 6：构建失败 / 网站没更新

### 对 OpenCode 说的话

```
网站好像没更新。请检查：1) git push 有没有成功 2) 运行 npm run build 看有没有报错 3) 如果有报错帮我修好
```

### 如果想去 Netlify 看构建日志
1. 登录 [netlify.com](https://netlify.com)
2. 在 Sites 列表里找到 CHITEK 的站点
3. 点 **Deploys** 页签 → 看最新的那一条是成功还是失败
4. 如果失败了，点进去看日志，把红字部分截图发给 OpenCode 修

---

## 任务 7：加一个全新的页面（比如产品页）

### 对 OpenCode 说的话

```
请帮我创建一个新页面：[英文路径，如 /new-product]

页面内容描述：[说明页面要包含什么内容]

参考 src/pages/en/products/active-harmonic-filter.astro 的结构来做。
完成后创建 5 个语言版本，确认构建通过。
```

---

## 操作铁律（告诉 OpenCode 时不需要说这些，AI 会自己遵守）

1. **不要手动编辑 `.astro` 文件**——让 OpenCode 来改
2. **每次推送前必须跑 `npm run build`** ——确保构建通过再上线
3. **如果构建失败，上网查日志 → 贴给 OpenCode 修 → 重新推**
4. **不要删文件**——不确定时先问交接人
5. 如果 OpenCode 停下来问问题不知道怎么回答 → 说"先按最合理的方案继续，有问题再说"

---

## 紧急情况

### 网站完全不显示了
别慌。登录 Netlify → 点 Deploys → 找到**上一次成功的构建** → 点右侧三个点 → 选 **Retry deploy**（用这个版本恢复上线）。这不会丢失任何代码改动，只是暂时回退到旧版本。

然后拍下错误页面，贴给交接人。
