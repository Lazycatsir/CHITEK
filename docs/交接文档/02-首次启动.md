# 首次启动 —— 拿到项目后的第一天

## 第 1 步：拿到项目文件夹

**方式一（推荐）：复制整个文件夹**
交接人把 CHITEK 文件夹整个复制给你（U盘/网盘/共享盘）。
你放在硬盘上，比如 `D:\CHITEK\`。

**方式二：从 GitHub 克隆**
如果你已配置好 SSH 密钥，在终端运行：
```bash
git clone git@github.com:Lazycatsir/CHITEK.git
cd CHITEK
```

## 第 2 步：装依赖

在项目文件夹里打开终端（cmd/PowerShell/终端），运行：
```bash
npm install
```
等它跑完（可能需要 1-2 分钟），不要中途关掉。

## 第 3 步：检查能不能运行

```bash
npm run dev
```
终端会显示类似：
```
  http://localhost:4321/
```
在浏览器打开这个地址，能看到网站首页就 OK。按 `Ctrl+C` 关闭。

## 第 4 步：配置 GitHub 推送（关键！否则改了发不出去）

有两种方式，选一个。

### 方式 A：用 HTTPS + Token（推荐，简单）
1. 到 [github.com > Settings > Developer settings > Personal access tokens](https://github.com/settings/tokens)
2. 点 "Generate new token (classic)"，勾 `repo` 权限
3. 复制生成的 token（类似 `ghp_xxxx...`）
4. 改一下仓库的远程地址（在项目文件夹里打开终端，运行）：
```bash
git remote set-url origin https://你的GitHub用户名:你的token@github.com/Lazycatsir/CHITEK.git
```

### 方式 B：用 SSH（传统，需要交接人配合）
1. 生成密钥：`ssh-keygen -t ed25519`（一路回车）
2. 复制公钥：`cat ~/.ssh/id_ed25519.pub`
3. 把输出的内容发给交接人，让他加到 GitHub 仓库的 Deploy keys 里

### 验证推送
```bash
git push origin master
```
不报错就 OK。

## 第 5 步：确认 Netlify 自动部署

1. 随便改个文件（比如把首页年份改到 2026）
2. OpenCode 修改后，让它推送到 GitHub
3. 登录 [netlify.com](https://netlify.com) → 你的站点 → **Deploys** 标签
4. 应该能看到一条新的 **Production deploy** 正在构建
5. 等一两分钟，构建成功后 → 你的网站就更新了
6. （先把年份改回来）

## 第 6 步：正式起跑

以上都成功后，就可以去读 `03-日常任务手册.md`，开始日常操作了。
