# 竞品一页纸 · 填空模板（AHF / SVG）

> 用法：每个竞品复制一份，文件名写 `竞品-{名称}.md`。
> 字段**固定不要增删**，否则无法横向对比。
> **填不出来就写「待核实」——写「待核实」比写错好。**
> 配套阅读：`docs/竞品分析拓展手册.html`（每个字段的判断口径都在里面）

## 附：三个判断（每个竞品填完后，主动产出这三条）

| 判断 | 必须写成的格式 | 本周动作 |
|------|---------------|---------|
| ① 它从哪里赢 | 它靠 ____（哪个引擎 / 哪个壁垒 / 哪一步动作），所以拿下了 ____（哪类客户 / 哪个标段） | 挑一条机制，评估 30 天内能否做出最小版本 |
| ② 它从哪里可能输 | 它在 ____ 上是缺的（证据：____），所以遇到 ____ 类型客户时会丢单 | 写成一句销售能直接背的话术，真实比稿中试一次 |
| ③ 我们该从哪里切进去 | 我们从 ____ 切进去，先在 ____（哪个页面 / 哪份物料 / 哪个渠道）落地 | 排进本周排期，不排期等于没做 |
