0 · 这篇记录是干什么的

一句话：把一张「看对手怎么赢」的方法论图，变成我们电能质量行业里真正能跑一遍的动作。那张图本身是消费品牌 / DTC 电商的语言，套到工业设备上要改三处——漏斗、转化机制、复购逻辑（见第 1 节）。下面四步是改完之后能直接照着做的版本。

用法：先选 5 个竞品，用《一页纸模板》每个填一张，再用本篇的「收口」只产出 3 个判断。不要再产出一份「竞品分析报告」，报告没人看。

1 · 为什么不能直接用原图（3 个失灵点，用类比讲）

失灵点 1 · 漏斗：客户不是「刷到就买」

原图以为客户是刷到 → 点击 → 下单，像在电商买件衣服。实际 AHF / SVG 像装修一栋楼：要找设计院画进图、找盘柜厂接进去、找采购谈价、找业主拍板，1–6 个月才签约，中间任何一环都能否决你。所以漏斗是：

触达 → 询盘 → 有效询盘 → 技术方案 → 报价 → 验厂 / 打样 → 签约 → 复购（多站点）

失灵点 2 · 转化：没人因为「满减」签一台滤波器

原图靠折扣、满减、bundle、赠品、订阅。工业品里这些基本是空的。客户真正反复问的是四件事：参数对得上吗、认证进得去吗、有人用过吗、交期和售后你敢写进合同吗。价格只是筛子，不是钩子。

失灵点 3 · 复购：设备十年不坏，没有耗材

原图靠耗材、会员、订阅。AHF / SVG 寿命 10 年以上、几乎无耗材、没有「每月续费」。真实的复购来自四个方向：同一个客户的第二个厂区、同一站点的容量扩容、SiC 换代升级、经销商与盘柜厂的下一次进货。

数字钉子（记下来，对外不讲、对内当标尺）： 有源滤波器在滤波器品类里已占 38%（2026）；低压段占 66%；50–200 A 容量段占 39%——这是我们和对手贴身肉搏的主战场。谁在主战场没站住，就不算正面竞品。

合计约 3 个工作日 / 5 个竞品。不要一次填 20 个，填 5 个就够定位。

第 1 步 · 市场位置：它在哪

做什么：把它的「基本身份」填进一页纸——阵营（出海同价位段 / 国际平台商 / AHF 专家 / 器件组件系）、主 SKU 容量段、认证清单、主攻买方（EPC / 盘柜厂 / 终端工厂 / OEM）、品牌阶段。

怎么判断强 / 弱（看三个信号）：

  • 官网每个系列有独立 URL + 独立参数表 + 可下载 datasheet = 强；全挤一页、参数用图片 = 弱；
  • 认证 PDF 可下载、编号可在 UL Product iQ / TÜV 查 = 强；只写「CE certified」四个字 = 弱；
  • 案例带行业 + 规模 + 治理前后 THD 数据 + 照片 = 强；「某工业客户」、无图 = 弱。
数字钉子：低压 50–200 A 占 39%。先看它的主 SKU 是不是压在这个段——压在段里才算正面对手，压在别处可以错位共存。

一句自检：它的主容量段和认证，覆盖我们要打的标段吗？

第 2 步 · 增长来源：它靠什么长大

做什么：判断它靠哪个引擎长大。原图让你数它做了哪些渠道，更重要的是判「靠什么」——是被真需求拉起来的，还是被投放砸出来的。

六个引擎（看它落在哪个）

引擎怎么认持续性
① SEO / 内容拉动50+ 技术长文 + 行业分站 + 选型计算器最耐久，停投也不归零
② 付费投放推动Google / LinkedIn 广告位、B2B 平台最高等级会员停投即停，看承接页
③ 展会与地面一年几场、展位面积、是否本地展工业主渠道，强但地域性
④ 渠道网络代理区域 + 报备保护 + 本地库存慢但质量高
⑤ 贴牌 / 代工拉动为其他品牌代工、白标政策量大利薄，不可学
⑥ 融资 / 补贴驱动近期融资、产能扩张公告现金来自资本 → 敢打价格战

怎么判断：看它的落地页能不能承接——有独立产品页 + 询盘表单 = 有资产；只有平台店铺、没有官网产品页 = 靠买流量。看内容资产——有分行业长文 + 工具页，说明增长停不下来。

一句自检：它的产品页，能让客户拿着去报价吗？能 = 强；不能 = 我们的口子。

第 3 步 · 成交放大：它怎么把流量变订单（最值钱的一步）

做什么：拆它的「看到广告 → 签约」全链路。原图的六步信息顺序可以直接用，只是把最后一步换掉：

是什么 → 谁适合 → 为什么需要 → 为什么值得买 → 为什么信它 → 为什么现在买

工业品把「为什么现在买」换成：交期承诺 + 项目报备保护 + 首台样机政策 + 电价 / 罚款压力（这一项最常被漏掉，但工业品也怕「再等等」）。

钩子只有三类，多了全是废话

类型能用什么（必须带可验证证据）反面教材
① 数字响应 <50 µs、效率 >99%、可治理到 50 次谐波、THDi 从 28% 降到 4.6%「高效、智能、环保」——等于没说
② 权威IEC 62477 / UL / 国网入围 / 第三方型式试验报告「行业领先」——谁都这么写
③ 场景数据中心 UPS 并机环流、光刻机 5 ms 电压容忍、光伏电站无功「广泛应用于各行业」——等于没指任何行业
可直接背的数字话术：
  • 别写「高效」——写「THDi 从 28% 降到 4.6%，满足 IEEE 519 限值」；
  • 别写「响应快」——写「响应 <50 µs，比电网扰动快一个数量级」；
  • 别写「可靠」——写「IEC 62477 认证，证书编号可查」。把形容词换成带单位的数字，客户才信。

信任补丁（工业品最强的一道）：质保几年、响应几小时到场、第三方检测报告、带前后数据的案例——这些必须写成具体数字，写进页面也写进合同。写「我们服务很好」不如写「备件 24 小时到场」。

一句自检：它的询盘表单筛客户吗？（只有姓名 + 邮箱的，一半是垃圾询盘）

第 4 步 · 优势持续性：它能守多久

做什么：把它的每个优势往四类壁垒里塞，看落在哪一档。这一步专门用来防止把「看起来强」误判成「攻不动」。

档位AHF / SVG 行业里的具体条目会不会被轻易复制
真壁垒SiC 器件与驱动、谐波提取 / 并机均流算法、认证与准入（UL / 国网入围）、自有产线、长期运行数据需时间 + 钱 + 人，按「季」计
半壁垒认证齐全度、案例数量、区域服务网点、经销商关系要花 1–2 年
表面壁垒好看的渲染图、齐全目录册、标准报价模板、展位装修一季内可平替
伪壁垒融资额、广告量、流量、社媒粉丝、销售人数、注册资本和「客户为什么买你」无关
数字钉子（用来拆伪壁垒的话术）：MTE 已公开 SyntriX AHF 的 >99% 效率、<50 µs 响应——这就是真壁垒的「刻度」。任何对手说「高效」时，拿这个对标；说不出具体数字的，大概率是表面壁垒。

一句自检：它真正守得住的优势，只有一条吗？写不出一条，说明它没真壁垒——那它就是能被切进去的口子。

收口 · 只产出 3 个判断

竞品分析终点不是报告，是三个判断，每个必须带一条本周动作，否则判断停在口号层。

判断必须写成的格式本周动作
① 它从哪赢它靠 ____（引擎 / 壁垒 / 动作），所以拿下了 ____（客户 / 标段）挑一条机制，评估 30 天内能否做最小版本
② 它从哪可能输它在 ____ 上缺（证据：____），遇到 ____ 客户会丢单写成销售能背的一句话，真实比稿试一次
③ 我们该从哪切我们从 ____ 切，先在 ____（页面 / 物料 / 渠道）落地排进本周排期，不排期等于没做

落到独立站：4 主线对应动作

三个判断不能停在 PPT 上，要接进现有的《独立站运营计划》4 条主线：

判断产出对应主线动作
广告钩子产品页塑造首屏形容词换具体数字 / 认证名
六步信息顺序产品页塑造逐页核对 8 个产品页，缺步补步（最低成本改造）
容量段 / 关键词关键词矩阵补竞品覆盖、我未覆盖的容量段词与行业词
它靠什么增长网站结构它靠行业页我们就优先建行业页；靠工具页就优先做选型计算器
信任补丁产品页塑造认证 PDF + 质保 / 响应数字上页面；无真文件先用「Send me the spec」
薄弱环节（切口）内容 / 结构针对它做一页可搜内容或一个行业页
询盘筛选数据周报表单加 4 字段，看有效询盘率而非总询盘
复购路径销售表单加固定字段「客户同时在比哪几家」——三个月后你就有比任何报告都准的名单

红线（极简 5 条）

  • 不编数据：第三方估算只作内部判断，不得对外当事实陈述；
  • 不抄原文：不复制竞品官网文案、图片、datasheet；
  • 报价只作内部参考：渠道问到的价格、返点、报备政策不进任何对外物料；
  • 不承诺效果、不编案例：未授权不写客户名，不说未经证实的收益数字；
  • 写「待核实」比写错好：填不出的字段一律写「待核实」。

自检清单（跑完心里有数）

  • 它的主容量段是 50–200 A 吗？
  • 它的认证覆盖我们要进的市场吗？
  • 它的产品页能让客户拿着去报价吗？
  • 它有独立产品页 + 询盘表单吗（还是只靠平台店）？
  • 它的钩子是数字 / 权威 / 场景里的哪一类？
  • 它的案例带治理前后 THD 数据吗？
  • 它的询盘表单筛客户吗？
  • 它的复购从哪来——多站点、扩容、还是换代？
  • 它真正守得住的优势只有一条吗？
  • 它交付后有质保和响应时间写进合同吗？
