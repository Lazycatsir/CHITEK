科普文占领搜索首位 · CHITEK 反击清单

对应竞品分析 playbook 的「支柱二 增长来源 / 攻略记录 第2步」。本页两件事：① 对手靠科普文占首位是怎么运作的、CHITEK 怎么反击；② 一条 Google 搜索结果里「三段字体」分别来自哪。

一、对手靠科普文占首位，是怎么赢的

科普文 = 用「内容资产」打搜索，占领的是漏斗最顶端（触达→询盘）。陌生买家搜的是问题，不是品牌：

  • 「什么是谐波 / 谐波畸变率 THD 是什么」
  • 「有源滤波器 AHF 和 SVG 静止无功发生器 区别」
  • 「怎么选有源滤波器容量 / 50A 还是 100A」

为什么能排第一、还稳：

  1. 传统 10 条蓝链排第一：内容定义先行、事实密集、H2 直接命中查询词 → 相关性打分高。
  2. 同时被 AI Overviews 引用：Google AI 摘要引用 2–6 个来源，约 73% 来自自然排名前 10。一旦被引，出现「摘要 + 原文」双曝光，进一步吸走点击。
  3. 他们怎么做：教育型长文 + FAQ schema + Article/Organization schema + 主题簇（pillar 大文 + cluster 小文）+ E-E-A-T（作者资历、认证编号、真实案例）。

二、CHITEK 可执行的反击（7 步）

  1. 建科普内容簇：一篇 pillar（《有源滤波器 AHF 完整指南》）+ 多篇 cluster（选型 / 认证 / 谐波标准 / AHF vs SVG / 行业案例）。首段直接给定义（定义先行）。
  2. 补结构化数据：现有新闻已有 Article JSON-LD，再补 FAQPage + BreadcrumbList + WebSite（站点名就靠它）。让 AI Overview 更可能引你。
  3. 抢 AI Overview 引用：事实密度高、给结构化对比表、Organization schema、附工程师资历与认证编号。
  4. 多语言覆盖：en/es/ar 主攻 Google，zh 主攻百度（中文站不加载 GA4，但百度是主战场）。科普文四语同步产出。
  5. 内链接权：用 _internal_link_audit.py 把科普文与 products / solutions / 行业页互链，把「科普流量」导向产品页（触达→询盘）。
  6. 真实素材优先：正文来自 F:/下载/web-crawler/outreach/templates/ 真实草稿（百家号 / linkedin），严禁编造。
  7. 衡量指标：GSC / GA4 看科普文带来的自然流量与 generate_lead；不承诺排名，只承诺「持续产出 + 结构正确」。

三、一条 Google 结果里的「三段字体」从哪来

位置典型样式来源Google 是否改写
顶部标题链接 蓝色、字号最大 网页 <title> 标签。改写优先级：title → H1 → og:title → 锚文本 → WebSite schema → 其他页内文字。2026 起美区有 AI 生成标题实验（可能写出页面上没有的标题）。 是，约 6–7 成被改写
中间站点名 + 面包屑/路径 绿色或灰色 站点名来自 WebSite 结构化数据 / og:site_name / title / H1；路径来自 BreadcrumbList schema 或真实 URL。基本原样显示——即你认出的「原文」。 基本不改写
底部摘要片段 黑色/灰色、字号最小 meta description（首选）；无或不匹配查询时，回退到页面正文抓取拼接。 是，常从正文抓取
速记：被改写的两段是「顶部蓝标题」和「底部黑摘要」；你认出的「原文」是中间那行站点名+路径，Google 几乎不动它。另外还有 sitelinks（站点链接，全算法、无法手动设置）是额外红利，不在三段之内。

四、红线（对外禁用语）

  • 不编案例（案例须真实可查）。
  • 不承诺排名 / 不承诺效果（只承诺「持续产出 + 结构正确」）。
  • 第三方研究数据未经我方实测，不得对外引用为事实。
