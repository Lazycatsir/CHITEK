5. 发现与建议

整体结论：英文站颜色体系比字体收敛——核心色只有 brand-orange(#ff6b1a)、text-dark(#1a1a1a)、text-muted(#6b7280) 等，背景几乎只用 white / 几个 bg-* token。但存在三类“绕过 token”的写法，是“看起来不统一”的根因：
  • ① 命名冗余 token：electric-orange≡brand-orange、text-primary≡brand-navy、text-secondary≡brand-gray、footer-bg≡bg-footer 等共 7 组同值异名，应合并保留一套。
  • ② 混用默认 Tailwind 灰度：在自定义 text-text-muted(=gray-500) 之外，还大量直接用 text/bg/border-gray-* 与 slate-*（见 §4），且如 #111827 同时以 text-gray-900 与 text-[#111827] 两种写法出现——灰度来源不统一。
  • ③ arbitrary 写死非 token 色：如 text-[#a8401e](深橙)、text-[#0000EE](链接蓝) 等直接写死，主题换色不会跟随。
建议：把 §4 的 arbitrary / 默认灰度全部改回自定义 token（新增 link / ink token 替代 #0000EE / #111827；#a8401e 复用 text-brand-orange-dark 或新增 burnt-orange），并废弃冗余别名。
