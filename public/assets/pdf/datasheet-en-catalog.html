Model naming rules
M A F 100 3 4 R C

R: rail mounted; W: wall mounted; F: full cabinet; P: plug-in
3: three-phase three-wire system; 4: three-phase four-wire system
Voltage Rating: 2: 208V, 3: 400V, 4: 480V, 6: 690V, 8: 800V
Current/Power Capacity: 15-200A or 10-150Kvar
F: APF, G: SVG, A: ASVG, C: SPC
A: Anti-pollution type C: Silicon carbide type D: Distributed type L: Standardtype U: Ultra-slim type
